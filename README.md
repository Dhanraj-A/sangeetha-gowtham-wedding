# Sangeetha & Gowtham Wedding Invitation

## Opening interaction — final simplified version

There is **no arrow, no boy, and no extra button**.

The elegant circular S&G seal in the center is the only control. When the
user clicks/taps the seal, the envelope opens directly with the existing
cinematic envelope animation, followed by the normal wedding invitation.

All invitation details, countdown, map button, and scroll animations remain
frontend-only.
